
# Tic Tac Toe Game

## Description
A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript. This game allows two players to play alternately using O and X.

## Features
- Two-player gameplay (O and X).
- Winner detection.
- Displays winner message.
- Disabled boxes after a winner is declared.
- Reset Game functionality.
- New Game functionality.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
Tic-Tac-Toe-Game/
│
├── index.html
├── style.css
└── script.js

## How to Play
1. Open the game in your browser.
2. Player O starts the game.
3. Player X takes the next turn.
4. Match three symbols horizontally, vertically, or diagonally to win.
5. Click Reset Game or New Game to play again.
